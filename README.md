# Meu CV — Bianca Serafim

Currículo online desenvolvido para o Trabalho 01 de Tecnologias de Desenvolvimento para Internet III.

## Tecnologias
- HTML5
- CSS3
- JavaScript

## Recursos
- HTML semântico com `header`, `nav`, `main`, `section`, `aside` e `footer`.
- Layout responsivo.
- Menu mobile com JavaScript.
- Navegação suave entre as seções.
- Destaque automático da seção atual no menu.
- Interação de hover/foco nos cards.
- Mudança dinâmica da paleta de cores ao passar o mouse sobre tecnologias e projetos.
- Foto de perfil e identificação do IFSULDEMINAS.

## Estrutura
- `index.html` — estrutura e conteúdo.
- `style.css` — visual, responsividade e paletas.
- `script.js` — interações.
- `assets/` — foto, ícones de tecnologias e imagens dos projetos.
